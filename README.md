# 小芽拼读 · 拼音与英语启蒙

面向 **4–5 岁儿童** 的移动端点读启蒙页，适合在微信内打开。

## 内容

- **拼音模式**（默认）：声母 → 韵母 → 复韵母 → 平舌和翘舌，共 38 个发音点。
  - 每个发音点包含「发音 3 遍 + 例句 2 遍」的连续女声跟读。
  - 例句贴合幼儿园、学校生活和男孩兴趣（挖掘机、恐龙、消防车、汪汪队等）。
- **英语模式**：26 个大写字母 → 26 个小写字母，共 52 张卡片。
  - 每个字母包含「字母名 3 遍 + 例句和中文翻译 2 遍」的连续女声跟读。

## 本地预览

```bash
# 在项目根目录
python3 -m http.server 4173
```

然后浏览器打开 <http://127.0.0.1:4173/>（仅本机可访问）。

> 拼音与例句音频已经生成在 `assets/audio/` 下，无需联网。
